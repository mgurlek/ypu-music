# Code of Conduct / Davranış Kuralları

Be kind and respectful. Everyone is welcome, whatever their experience level, language or background. / Nazik ve saygılı olun. Deneyimi, dili ve geçmişi ne olursa olsun herkes buraya hoş geldi.

- Help beginners patiently. Questions are welcome.
- Criticise code and ideas, never people.
- No harassment, insults, discrimination or spam.
- Do not post other people's private information.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, contact the maintainer through the email on their [GitHub profile](https://github.com/mgurlek). / İhlalleri GitHub profilindeki e-posta üzerinden bildirebilirsiniz.

This is a short rule set in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
