# Security Policy

YPU Music runs only on your own computer, listens on `127.0.0.1`, and has no login. Do not expose it to the internet or your network.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. Use GitHub's private reporting: **Security tab > Report a vulnerability** on <https://github.com/mgurlek/ypu-music>. Describe what you found and how to reproduce it. We will answer as soon as we can.

Only the latest version on `main` is supported.

## Güvenlik açığı bildirimi

Güvenlik sorunu için herkese açık issue açmayın. Repo sayfasında **Security > Report a vulnerability** ile özel bildirim gönderin.
